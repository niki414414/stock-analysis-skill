# 六层框架回测结论 + v4.2修正建议

## 回测基本参数

- **回测窗口**：2026-03-01 → 2026-06-06
- **股票池**：34只（真实持有+观察池混合）
- **信号识别**：每15个交易日取一次信号日，共136个信号点
- **评判标准**：信号后15个交易日收益（入场≥3%=正确，拒绝后涨≥5%=漏单）
- **量化层**：Layer1/4/5/6自动计算；Layer2/3（事件催化/产业地位）未自动化

---

## 总体结果

| 指标 | 数值 |
|------|------|
| 总信号数 | 136 |
| 总准确率 | 53.7% |
| 错误入场 | 2次 |
| 漏单 | 61次 |
| ENTER平均收益 | +22.8% |
| REJECT/WAIT平均后续收益 | +6.8%（含大量漏单） |

**结论：框架极度保守，入场门槛过高，主要问题是漏单而非错误入场。**

## 按月准确率——4月是最大问题

| 月份 | 准确率 | 主要原因 |
|------|--------|---------|
| 3月 | 60.3% | 还行，修正期中规中矩 |
| **4月** | **32.4%** | **市场复苏初期，框架失效** |
| 5月 | 61.8% | 趋势确立后框架重新有效 |

**4月34个信号，23个漏单**——原因见下方"核心发现"。

## 核心发现（按严重程度排序）

### 1. D轨迹规则根本性错误（10个漏单）

**现象**：D轨迹（高位震荡，价格在high_baseline×0.92~1.10之间）一律REJECT，
但10个D漏单后续平均涨幅+27%，最高+48%（亨通光电）。

**关键发现：D漏单和D正确回避的60日涨幅几乎相同（42.5% vs 42.8%）**
→ 说明"高低位"本身根本不是判断依据，
→ 真正的区别是**市场所处阶段**：
  - 3月23日、4月14日的D = 市场复苏初期 → 继续涨
  - 3月2日、5月8日的D = 行情阶段性顶部 → 回调

**修正（v4.2）**：
```
D轨迹 → 不再直接REJECT，改为判断市场阶段：

IF D AND 市场状态 = "复苏期/主升期早中段":
    → 降级为 C 处理（右侧回踩入场）
    → 止损：比正常C更紧（近期低点-2%而非-3%）

IF D AND 市场状态 = "过热期/主升期晚段":
    → 保持 REJECT（高位博弈，风险收益比差）

IF D AND 无法判断市场阶段:
    → 标记为 D-待确认，要求人工判断后决定
```

---

### 2. E轨迹全部WAIT→13个漏单

**现象**：E轨迹（突破历史新高）全部判为WAIT等Layer2确认，
但13个E漏单后续平均+22%，华电辽能4月+54.5%，5月+46.4%。

**发现**：E出现在"主升期"赛道时，新高就是信号本身——不是"过热"而是"加速"。

**修正（v4.2）**：
```
E轨迹 → 不再一律WAIT，改为：

IF E AND sector_stage = "主升期" AND 近20日涨幅领先板块:
    → 视为 C+ 处理（等3日以上>3%的回踩后入场）
    → 入场条件：从近5日高点回调≥3%即可，不需要等到MA5

IF E AND Layer2催化已"充分定价":
    → 降级为 REJECT（靴子落地，不追）

IF E AND sector_stage = "整理期/调整期":
    → 保持 WAIT（需Layer2确认是否真突破）
```

---

### 3. A轨迹漏单最多（22个），4月几乎全军覆没

**现象**：A轨迹（下跌途中）一律REJECT，但22个A漏单后续平均+16.6%，
蜀道装备+58.2%，长电科技+47%，立讯精密+27.6%。

**分析**：4月这批A漏单的共同特点：
- 它们的板块在4月恰好开始主升（电力、半导体、PCB）
- 60日涨幅大多在-20%~+8%之间——不是真的弱，是"还没轮到"

**修正（v4.2）**：
```
A轨迹加"赛道轮动候选"判断：

IF A AND sector_stage(from market_status.yaml) = "主升期/启动期" 
  AND sector_priority = 1
  AND 板块近20日涨幅 > 10%:
    → 升级为 A⚠️（晚进场候选），强制Layer2/3核查
    → 不直接REJECT

IF A AND 上述条件不满足:
    → 保持 REJECT
```

---

### 4. C轨迹"跌破MA20→REJECT"规则误伤6个好机会

**现象**：7个C-REJECT案例全部触发"跌破MA20→过深拒绝"，
其中5个漏单后续平均+28.8%（永鼎股份+47.5%，中恒电气+46.3%）。

**发现**：3月中下旬是大盘整体回调，几乎所有股票都暂时跌破MA20，
但属于"整体性回调"而非个股问题，跌破MA20很快就收复。

**修正（v4.2）**：
```
C轨迹MA20规则：

IF C AND 价格 < MA20 AND 跌破幅度 < 10%:
    → 降级为 WAIT（不REJECT）
    → 等待收回MA20之上后入场
    → 入场条件：收盘站上MA20 AND 量比≥1.2

IF C AND 价格 < MA20 AND 跌破幅度 10-15%:
    → WAIT with 小仓警觉

IF C AND 价格 < MA20 AND 跌破幅度 > 15%:
    → REJECT（过深，趋势已破）
```

---

### 5. C+轨迹（强势上涨中）漏单4个

**现象**：002463沪电股份全窗口都是C+→WAIT，从81涨到133，一次都没买到。

**发现**：对于强势趋势股，"等回踩到MA5/MA10"等于永远等不到。

**修正（v4.2）**：
```
C+轨迹新入场规则（追涨型入场，需严格条件）：

IF C+ AND 近3日从近期高点回调 ≥ 3%:
    → 有效入场机会（短期调整，非趋势终结）
    → 止损：近3日低点下方2%

IF C+ AND 近5日连续未创新高:
    → 进入"等待区间"，若收盘跌破5日最低价 → 确认回踩，次日开盘入场
```

---

### 6. B轨迹左侧入场门槛过严（3个漏单）

**现象**：B轨迹（止跌蓄势）全部标记WAIT等止跌信号，
但大唐发电4月WAIT后+42.4%，璞泰来3月WAIT后+12.1%。

**现状**：当前B轨迹始终输出"继续等止跌信号"，从不给入场建议。

**修正（v4.2）**：
```
B轨迹左侧触发条件（明确化）：

满足以下3条中2条 → 给出左侧小仓入场建议（而非"继续等"）：
  1. 近5日低点不再创新低（低点抬升）
  2. 近5日成交量持续萎缩（抛压衰竭）
  3. 出现下影线较长K线（日内有人接）

满足 → ENTER 30%仓，止损=近期低点-3%
不满足 → WAIT，但明确告知"缺少哪个条件"
```

## 最重要的元结论：框架缺少市场阶段感知

**回测最大教训**：4月是市场从调整转复苏的拐点，
框架在拐点处几乎失灵（32.4%准确率）。

原因：框架用的是**个股技术轨迹**，但在市场拐点处，
**所有个股的技术形态都是"坏的"**（因为它们刚经历了回调）——
真正的信号不在个股层面，而在**市场层面**。

**v4.2新增：Layer 0 市场阶段识别（强制执行）**

```
在做任何个股轨迹判断之前，先判断市场当前阶段：

阶段A（调整末期/复苏初期）信号：
  - 大盘已经止跌2周以上
  - 两市成交额连续3日扩量
  - 大盘突破20日均线
  → 触发时：所有A轨迹升级为A⚠️，所有D轨迹降级为C处理

阶段B（主升期）信号：
  - 大盘在20日线上方运行
  - 板块轮动活跃（每周至少一个新板块启动）
  → 触发时：E轨迹可直接入场（不强制WAIT Layer2）

阶段C（过热末期）信号：
  - 大盘偏离MA20 > 15%
  - 两市成交额 > 4.5万亿
  → 触发时：D轨迹和E轨迹一律REJECT，C轨迹仍可入
```

## 框架准确性总结（v4.1 vs v4.2预期）

| 轨迹 | v4.1准确率 | 主要问题 | v4.2预期 |
|------|-----------|---------|---------|
| A | 56% | 漏单22个，板块轮动识别缺失 | 预期→65% |
| B | 67% | 左侧门槛模糊，3个漏单 | 预期→75% |
| C | 50% | MA20过严，6个漏单 | 预期→70% |
| C+ | 43% | 从不入场，永远等回踩 | 预期→60% |
| D | 57% | 10个漏单，时机判断缺位 | 预期→65% |
| E | 46% | 13个漏单，一律WAIT | 预期→62% |

**Why:** 回测窗口（2026年3-6月）正好是一轮完整的调整→复苏→主升行情，
框架在复苏初期（4月）失灵最严重，说明框架本身缺少对市场阶段变化的感知机制。

**How to apply:** 
1. 每次分析前先判断市场处于哪个阶段（Layer 0强制）
2. 根据市场阶段动态调整各轨迹的处理方式（见上方规则）
3. 在"复苏初期"阶段，对A和D轨迹应主动降低拒绝门槛

## 回测局限性说明

1. **Layer2/3未自动化**：事件催化和产业地位判断未参与回测，实际框架有这两层保护，漏单数量会少一些（过滤掉部分不该买的A轨迹股）
2. **信号日固定间隔**：每15个交易日取一次，实际操作会在更自然的时机分析，部分漏单在实操中会被捕捉
3. **样本池偏差**：34只股票均为用户选出的"有认知"标的，不代表全市场，漏单率在更宽样本中可能更低
