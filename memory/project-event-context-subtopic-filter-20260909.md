## 真实验收案例

当前结果能从`AI-SAAS-2026-001`召回AI安全相关历史线索，但因为“AI安全”只存在于宽事件的

## 本次只修这个问题

目标：保留上级事件作为产业背景，同时让细分主题正文只包含与查询词直接相关的证据、公司和
验证节点，不把上级事件的全部记录误当成细分主题热度或映射。

最小修改范围：

1. 区分`direct topic evidence`与`parent event context`；
2. 细分主题的材料、信号、修正和公司关系按查询词相关性过滤；
3. 上级事件仍返回，但明确标为背景，不计入细分主题直接证据数量；
4. 无独立事件时明确输出“尚未形成独立事件”，不得用宽主题事件替代；
5. 零结果时优先警告“主题未覆盖”，不只提示生命周期和价格响应缺失。

## 非目标

- 不新增数据库表、评分器或并列工具；
- 不建立AI安全专用规则或词表；
- 不修改现有事件内容和公司关系；
- 不连接资金、六层或选股流程；
- 不把共同出现、代表公司文字或上级事件关系自动升级为因果关系。
