## 背景（2026-07-10，9只股票分析引出的框架讨论）

对沪电股份/华工科技等做左侧/波段分析时暴露：`user_profile.yaml`的"趋势跟随+底仓持有"是2026-05-14建画像时的假设，在单边抱团行情里（进场价必然偏高、回撤又深）这套假设本身导致踏空或右侧追高被套。用户明确表态："不能死守画像"，但仍在摸索自己的交易原则，不希望框架帮他下判断，而是希望框架诚实标注"这里我确定"vs"这里该靠你自己感觉"。

## v4.9三项改动

**1. 市场分歧度信号**（`stock_data_fetcher.py`新增`fetch_market_breadth()`）
- 用tushare `pro.daily(trade_date=X)`算全市场涨跌家数比 + `limit_list_d`涨跌停数 + `index_daily`(000300.SH)指数涨跌
- 输出`regime_label`：普涨/抱团集中/权重股压制/普跌/震荡中性
- 验证：2026-07-09实际数据（指数+2.54%但仅46.3%个股上涨）→ 正确判定"抱团/集中"，与WebSearch人工核实的"超4600只个股下跌"结论一致
- 接入`market_environment.breadth`字段，Layer 1新增"分歧度检查"小节消费它

**2. 底仓/战术仓双仓位体系**（`user_profile.yaml`新增`tactical_position`配置块 + Layer 5"波段方案战术仓口径强化"）
- 不是画像作废，是底仓管一部分仓位（原有六层逻辑不变），战术仓单独一套更紧的规则管另一部分
- 关键发现：硬性约束第1条早就要求"每次都输出波段方案"，但实测发现波段方案经常照抄中线方案的止损/仓位口径，导致波段方案也在追高（沪电股份137进场案例，盈亏比仅0.34）
- 战术仓口径：止损=近1-3日K线最低点（不是MA60结构止损）、仓位上限12%（底仓25%的一半）、10个交易日到期强制减仓、盈亏比标准不降（仍要求≥2，下调的是止损距离和周期不是标准）

**3. 判断置信度标注**（`output-format-template.md`综合判断新增"判断置信度"字段）
- 高/中/低三档，低置信度触发条件：`regime_label`=抱团/集中或权重股压制、Qullamaggie门控MA10/MA20交叉附近、WebSearch与event地图/window模型结论不一致
- 目的：不让"技术上有确定结论"和"这里其实是分歧/转折点"看起来一样笃定

## 自我修正（2026-07-10晚，同日内发现）

深挖"轨迹E目标价"问题一整天（借鉴Minervini/Qullamaggie/Turtle/RRG/Choppiness，backtrader规范回测5只票2年数据）后，用户指出一个更根本的认知错误：**底仓/战术仓当时被设计成两套独立的分析口径**（战术仓有自己的止损基准/目标价公式/仓位上限/持有期），这个设计隐含假设"个股层面能明确切换趋势市/震荡市两套打法"——但这个假设本身，恰恰是同一天backtrader回测反复验证不成立的东西（Choppiness门控在5只票里3只让结果更差）。假设不成立，建立在其上的"战术仓独立公式"就是悬空的过度设计。

**用户的重新定位**：如果个股层面不做硬性策略切换，底仓/战术仓的意义应该**退回成单纯的资金分配比例**（同一套六层分析结果，只是决定这次给多少仓位、打算拿多久），而不是两套并行的止损止盈计算逻辑。且这个切换本身也不该是硬开关，应该是"趋势信心连续刻度"决定仓位怎么在两端之间滑动分配——这个连续刻度怎么定义（大概率是市场分歧度+个股60日参与度+行业催化阶段加权），是下一个专项要做的事。

**How to apply（更新，已执行）**：当天已经把`analysis-prompt-template.md`的"战术仓独立公式"简化掉——波段方案和中线方案现在共用同一套止损/目标位判断（六层分析支撑位+high_baseline），战术仓只剩仓位分配(12%)和复查窗口(10个交易日，非强制平仓)两个参数，`user_profile.yaml`同步更新，已推送备份仓库。**"连续趋势信心刻度决定仓位分配比例"这个更完整的方案仍未实现**，用户明确说要再深思熟虑，留待专项时间，这部分不要在没想清楚前动手写。

## 已知边界（诚实说明，不过度承诺）

- 分歧度信号能量化"普涨vs抱团"，但**真正的情绪转折点识别仍然是技术指标结构性滞后的地方**——没有试图做一个"情绪打分器"去替代用户自己读外部评论的判断，只是让框架在"这里可能是转折"时主动降低自己的确信度显示，把主动权交还给用户
- 用户自己的交易原则仍在摸索中，这套改动是给他的判断提供更诚实的输入，不是替他形成原则

**Why:** 用户指出在单边集中度高的行情中，老画像的"找低分位+等回踩"根本不成立，追高必然发生但回撤剧烈容易触发止损/止盈——如果不调整，等于让框架的建议系统性地把筹码在高位交出去。
**How to apply:** 之后每次跑`/stock-analysis`，Layer 1自动检查`regime_label`，波段方案必须用`tactical_position`独立口径计算，综合判断必须标注置信度。参见[[project-leftside-rightside-unification]]（同一类"框架该不该分场景/模式"的设计问题）、[[feedback_tool_integration_standard]]（新字段必须真正接入消费方，不能只加了计算不接输出）。
