用户2026-03入市初期还会看宏观信号（美元指数、地缘冲突等）联动判断有色/电力/创新药机会，当时也确实买过这几个板块，但结果是亏损。后续科技股走出持续单边行情，用户在科技里被套，精力和仓位反复纠缠在科技板块内部，逐渐形成思维定势：一提有色/电力/创新药，本能反应还是"那是会亏钱的板块"，即使市场环境已经变了，也不敢进场，动作偏慢。

2026-07-23自述："现在也惯性的觉得是这种情况，动作就比较慢，也不敢进入。"

**Why:** 这是用户自己观察到的行为模式（近因偏误/心理锚定），不是一次性判断错误，而是可能反复影响未来选股/风格切换决策的持续性倾向。用户对此有自我觉察，希望打破这个惯性。

**How to apply:** 以后讨论有色/电力/创新药或任何用户历史上亏损过的板块时，主动区分"当时亏损的具体原因/regime"和"当前市场条件"是否还成立，用[[feedback_narrative_vs_regime_context]]式的regime校准方法给出数据依据，而不是让用户单凭"以前在这亏过"的直觉决定进不进场。同时可结合market-outlook技能主动提示宏观信号（美元指数、地缘事件等）对有色/贵金属等板块的映射，帮用户重新捡起入市初期就有的宏观联动习惯，抵消"只盯科技"的惯性。
