`stock_data_fetcher.py`里判断A股属于上证还是深证的逻辑，13处都写成`code.startswith(("600", "601", "603", "688"))`，**遗漏了"605"这个合法的上证主板前缀**（比如605111新洁能）。命中605开头的股票会被误判成深证代码(.SZ)，导致Tushare/yfinance等全部数据源返回空，报错"all data sources failed"。

**Why：** 605是这几年新股常用的上证主板前缀之一，量不算特别大但确实存在，之前分析的股票可能都没撞上605开头的，这次分析605111才第一次触发。13处判断逻辑是复制粘贴的同一个错误元组，不是单点bug。

**How to apply：** 2026-07-22已经用脚本一次性把13处都改成`("600", "601", "603", "605", "688")`（含两处扩展版`("600","601","603","688","51","58")`加了605进去），已同步到迁移包。以后如果又遇到某个具体股票代码"所有数据源都失败"，先检查是不是这种前缀分类遗漏问题，不要一上来就怀疑是数据源本身挂了。
