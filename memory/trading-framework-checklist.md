# 完整交易框架 v4.2（市场阶段感知版）

## 核心原则

**不再是"六层全通过才入场"，而是：**
- **Layer 0（新增）**：先判断市场阶段——阶段决定各轨迹的处理方式
- 第1-3层：定性门槛，任何一层否决即放弃
- 第4层：判断当前处于哪条轨迹（A/B/C/C+/D/E），结合市场阶段决定操作
- 第5层：根据轨迹类型给出具体入场条件（左侧/右侧/等待）
- 第6层：量能模式验证，作为加仓/减仓的辅助依据

等待本身就是仓位管理；没有底仓时，左侧小仓是"保证上车"的机制，不是冒险。

**v4.2回测依据（2026年3-6月，34只股票，136个信号点）：**
- 总准确率53.7%，ENTER决策准确率66.7%，但漏单61个
- 4月准确率仅32.4%——市场复苏期框架集体失效，根本原因：缺少市场阶段感知
- D轨迹漏单与正确回避的60日涨幅几乎相同（42.5% vs 42.8%），高低位本身不是判断依据

**v3.3新增原则（保留）：拒绝时必须运行"遗漏风险扫描"**
每次输出❌拒绝或⏳等待，自动扫描两类框架边界遗漏模式：
- 类型一（直线动量股）：偏MA10>20% + 极度缩量记录 + 相对强度>30% + 当日放量 → 4项均满足则给出4条手动核查清单
- 类型二（晚进场主题股）：60日<5% + 近5日>5% + 轨迹A → 3项均满足则给出4条供应链/资金/事件核查清单
框架不能自动捕获这两类，但可以提醒用户手动核查，避免规律性漏单。

## Layer 0：市场阶段识别（六层分析前必做）

**核心逻辑**：在市场拐点处，所有个股的技术形态都是"坏的"——这时个股技术分析会系统性失效。先判断市场阶段，再决定如何解读个股轨迹。

### 三种市场阶段及识别方法

**阶段A：调整末期/复苏初期**（框架最容易漏单的阶段）

识别信号（满足2条以上）：
- 大盘已从近期低点反弹，且止跌超过10个交易日
- 两市成交额连续3日以上扩量（每日较前日增加）
- 大盘突破20日均线并站稳（非单日假突破）
- 板块轮动加快，每周有1个以上新板块启动

触发后的规则调整：
- A轨迹个股：若所属板块 sector_stage = "主升期/启动期"，**自动升级为A⚠️**，进行Layer2/3核查而非直接REJECT
- D轨迹个股：**不直接降级为C**，需先检查D股已回调幅度：
  - 从近期高点已回调 ≥ 10% → 降级为C处理（有真实回踩），止损更紧
  - 从近期高点回调 < 10% → **保持REJECT**（仍在顶部，下行风险大）
  - 回测依据：3月2日D→C（价格在顶部）导致蜀道装备-22.8%、中恒电气-9.6%等多次错误入场
- B轨迹：左侧门槛降低，满足止跌三要素中2条即可建仓（正常需3条）

---

**阶段B：主升期**（框架相对有效的阶段）

识别信号（满足以下特征）：
- 大盘在20日线上方平稳运行
- 成交额维持在日均3万亿以上
- 每1-2周有新板块接力启动（轮动连续性强）

触发后的规则调整：
- E轨迹个股：不直接进入，需检查当前价格已回调幅度：
  - 从突破点（high_baseline×1.10）回调 ≥ 5% → 视为C+，等额外3%回踩后入场
  - 回调 < 5% → **保持WAIT**（仍在顶部，不追）
  - 回测依据：3月2日E→C+（价格在高位）导致中材科技-16.6%、菲利华-17.9%等错误入场
- A轨迹：sector_priority = 1 且板块近20日涨幅>10% → 自动升级A⚠️
- C+轨迹：允许趋势跟踪入场（见C+规则）

---

**阶段C：过热末期**（框架需要收紧的阶段）

识别信号（满足以下特征）：
- 大盘偏离MA20超过15%
- 两市成交额 > 4.5万亿（极热）
- 涨停股数量异常多（>200家/日）

触发后的规则调整：
- D轨迹：**保持REJECT**（不再降级为C）
- E轨迹：**保持REJECT**（新高追涨风险极高）
- C轨迹：提高量能要求（量比≤0.7才算缩量，标准比平时更严）

---

**阶段D：高位结构性分化**（拥挤度极高，指数与个股反向）

识别信号（满足3条以上触发）：
- 大盘在MA20上方（不是复苏期）
- 两市成交额持续≥2.5万亿，但指数不持续创新高
- 板块宽度极低：当日上涨板块<35%（多数板块在跌）
- ETF资金高度集中：前2-3大ETF净流入占全市场ETF流入>60%
- 指数与个股涨跌反向：指数涨但上涨家数<40%，或反之，连续3日出现

数据佐证：2026年5月底，东方财富首席策略师陈果指出，5%的股票贡献了45%以上的全市场成交量，达到历史罕见水平，历史上每次均发生大幅变盘。6月5日出现"指数跌3.2%但个股多数上涨"的极端结构分化。

两个前置概念：
- **集中赛道**：当前ETF净流入占比最高的1-2个板块（如AI/科技）
- **轮动赛道**：板块宽度低但ETF流入开始回流的板块

触发后的规则调整：
- **整体仓位上限降至60%**（拥挤度极高，踩踏时跌得最快）
- C+（集中赛道内）：仓位×0.6，止损收至近3日低点-1.5%（比正常更紧）
- D（集中赛道内）：**保持REJECT**（高位集中+高位震荡=双重风险）
- E（集中赛道内）：**REJECT**（极端拥挤时新高是逃命盘）
- A/B（非集中赛道）：**升级为轮动候选**，进Layer2/3核查（资金正在从集中赛道流出）
- C（非集中赛道）：正常右侧规则，但优先级提升

第1层新增检查：
- IF 指数涨幅>0.5% AND 上涨家数<40% → 标记"指数强个股弱"警示，当日分析仓位×0.8
- IF 连续3日指数与个股反向 → 确认阶段D，触发上方全部规则

阶段D退出判断（满足任一解除）：
- 板块宽度恢复>50%（资金开始扩散）
- 集中赛道ETF连续5日净流出
- 大盘跌破MA20超过3日（退回阶段A）

---

**结构性牛市Bridge触发规则**（v4.3新增，替代"结构牛覆盖开关"）

背景：在政策背书+资金无替代选择+产业真实落地的结构牛中（参考924行情、AI主题2025-2026），经典技术框架会系统性漏单。但简单放宽规则会引入等量的错误（回测验证：三个宽泛条件在亏损案例和盈利案例上结果相同）。

正确做法：不放宽技术规则，而是在特定条件下**用Phase 2 Bridge替代第4-6层**。

触发条件（三条同时满足）：
1. 市场处于阶段A或阶段B（非过热）
2. Layer2催化强度高（国家政策直接点名 + 产业链直接受益，非蹭概念）
3. 个股已从近期高点回调≥15%

触发结果：
- 不走A/D轨迹的REJECT逻辑
- 强制运行Phase 2 Bridge（4条财务验证）：
  ① 合同负债近2季持续增长（翻倍增长可豁免其他条件）
  ② 毛利率同比改善
  ③ 存货周转同比加快
  ④ 个股跌幅<板块ETF跌幅×0.8（板块内抗跌）
- Bridge≥3条通过 → 给出左侧小仓建议（20%仓位）
- Bridge<3条 → 维持REJECT，"AI主题"标签本身不构成入场理由

回测依据：工业富联2026年3月底买入正确，是因为Q1合同负债+223%（Bridge条件①翻倍豁免），而非因为"AI牛市"概念。同时期蜀道装备满足宽泛条件却亏损-22.8%，因为业绩未真实兑现（Bridge未通过）。

**阶段判断不确定时**：按**阶段B默认规则**执行（不调整任何规则，照常走六层）。

## 第1层：市场水位（定性门槛）

**检查内容：**
- 沪深300 / 创业板至少一个在20日线上方
- 两市成交额无连续3日以上萎缩
- 跌停家数无异常扩散（>80家视为风险信号）
- **目标板块近20日表现 vs 大盘**：是跑赢还是跑输？

**关键判断：**
板块整体在回调 ≠ 板块主线逻辑破坏。区分方法：
- 整个板块一起跌（情绪性回调）→ 是买入机会
- 板块内强股继续上涨、弱股下跌（分化）→ 选强股
- 板块指数跌破60日线且成分股普遍破位 → 主线退潮，暂停

**通过标准：** 大盘无系统性风险；板块处于主线逻辑未破的回调期。

## 第2层：事件催化（定性门槛）

**检查内容：**
- 有明确可交易事件，且能说清楚"谁受益、为什么、多大"
- 事件处于**预期建立期**或**刚开始兑现期**，未完全兑现

**新增：催化定价程度判断**

| 催化距今 | 股价表现 | 判断 | 操作含义 |
|---------|---------|------|---------|
| >30天 | 尚未启动 | 未定价 | 等待池，观察 |
| 15-30天 | 小幅上涨 | 初步定价 | 左侧建仓窗口 |
| 7-15天 | 已涨10-20% | 部分定价 | 止跌后左侧；或等右侧触发 |
| <7天 | 已涨20%+ | 充分定价 | 不追；等兑现后反应 |
| 当天兑现 | 任何价格 | 靴子落地 | 不买；观察次日反应再判断 |

**通过标准：** 催化逻辑清晰，且尚未完全定价。

## 第3层：产业地位（定性门槛）

**检查内容：**
- 非ST，无退市风险
- 有真实业务/订单与催化事件直接挂钩（不是蹭概念）
- 在板块内的地位：核心受益还是边缘受益？

**额外判断：是否为"板块里独立下跌"的标的？**
同板块其他股票反弹时，这只股票仍在下跌 → 说明有独立的筹码问题（主力撤退或负面信息），不适用任何买点逻辑，直接排除。

**通过标准：** 有真实受益逻辑；无异常独立下跌行为。

## 第4层：趋势结构（动态轨迹判断）

**不再只看"今天MA排列"，而是看三段时间的动态轨迹。**

### 三段时间分析：

**① 60天大趋势（定性）**
这只股票是否真实参与了本轮主线行情？
- 计算：当前价 vs 60天前价格，涨幅是否显著（>20%）
- MA60的正确用法：看**斜率**不看位置
  - MA60向上倾斜 → 中期趋势健康，回调是机会
  - MA60走平 → 中期趋势中性，需要催化推动
  - MA60向下倾斜 → 中期趋势已坏，不做左侧

**② 20天近期节奏（定量）**
事件催化出现后，这只股票的反应是领先、同步还是滞后于板块？
- 领先（涨得多、跌得少）→ 主力在里面，筹码质量好
- 同步 → 跟着板块走，中性
- 滞后（涨得少或催化期间没涨）→ 无主力认可，慎重

**③ 5天微观信号（定位）**
用于最终确认轨迹类型，见下方。

### 四种轨迹分类（核心判断）：

| 轨迹 | 特征 | 对应操作（v4.2更新）|
|------|------|---------|
| A：下跌途中 | 60天<3% 且近5日<5%；OR 低点持续新低；OR 板块涨时此股仍跌 | 默认不买。**但**：若市场处于阶段A/B 且板块sector_stage="主升期/启动期"→自动升级A⚠️ |
| A⚠️：晚进场候选 | 60天<5% 但近5日>5%；OR 市场阶段A+板块主升期 | 核查Layer2/3，直接受益则进B流程；仓位20-25%（比正常B轨迹更小）|
| B：下跌末期止跌蓄势 | 60天有参与；近期回调是板块性的；低点不再创新低；量能萎缩 | **左侧入场窗口**。市场阶段A时门槛降低（2/3条件满足即可）|
| C：上涨途中正常回踩 | MA60向上；近20天领先或同步；回踩到MA5/MA10附近 | **右侧再入窗口**。MA20跌破≤15%→WAIT（不REJECT）；跌破>15%→REJECT |
| C+：强势上涨途中 | MA60向上；近20天持续领先；价格未出现有效回踩 | 等3日回调≥3%或5日连续未创新高→入场。不强制等MA5/MA10 |
| D：高位震荡 | price 在 high_baseline×0.92~1.10之间；量能放大后萎缩；MA紊乱 | **按市场阶段判断**：阶段A/B→降级为C处理；阶段C/过热→REJECT |
| E：突破新高 | price > high_baseline×1.10 | **按市场阶段判断**：阶段B主升期→视为C+入场；阶段C过热→REJECT；Layer2催化已充分定价→REJECT |

**v3.2止损规则（数据验证）**：ATR×2与结构止损取较低值；高波动(>40%)强制ATR止损+仓位×0.7
**v3.3新增（4只样本验证）**：
- 催化距今≤15天均视为"事件驱动"（原10天扩展至15天）
- 缩量压缩后放量突破：偏MA10>20% + 前日量比<0.3x + 当日量比≥2x + Layer2完整 → 盘中30%仓介入，止损=缩量日低点×0.97
- 晚进场候选：60日<5%但近20日>5%+Layer2直接催化 → 不判A，进Layer2/3核查
- 遗漏风险扫描：每次拒绝/等待时自动输出两类漏单检测+手动核查清单
- 框架边界声明：线性动量股（偏MA10>20%且无缩量压缩形态）不在框架适用范围，承认漏单
**v3.4新增（6只样本验证）**：
- C轨迹强制Layer2：无催化C轨迹→观望。数据：有催化平均+14.7%，无催化-6.8%
- type2扫描MA60斜率过滤：MA60≤0时不触发。正值准确率100%，负值假阳性100%

**v4.0新增（跨周期验证）**：
- Layer0大盘阶段识别：5项评分→Phase1/2/3，决定Layer4用技术轨迹还是基本面动量桥
- Phase 2 Bridge（替代Layer4技术轨迹）：
  ① 合同负债近2季持续增长（一票关键项，翻倍增长可豁免其他）
  ② 毛利率同比改善
  ③ 存货周转同比加快
  ④ 个股跌幅<板块ETF跌幅×0.8（板块内抗跌，非vs大盘）
  4项满足≥3项通过；仓位系数Phase2=0.6，止损ATR×3
  数据验证：工业富联2025Q1合同负债+223%，Bridge给出买点，实际+29%
- 动量行情输出类型：偏MA10>20%+近10日涨>20%+无回踩→不走六层，输出手动核查清单
- 排除清单（仅排除）：ST/连续亏损/与催化产业链无交集；不限定"必须前三名"

- 价格在MA60下方已超过5天且MA60向下：轨迹A特征，回避

## 第5层：买点位置（左侧/右侧分层）

**根据第4层的轨迹类型，进入不同的买点判断流程。**

### 轨迹B → 左侧入场流程

**止跌信号三要素：**
1. 连续2-3天低点不再创新低（低点抬升）
2. 下跌日成交量持续萎缩（抛压衰竭）
3. 出现下影线较长的K线（日内有人在接）

**左侧入场条件（v4.2明确化）：**

| 止跌信号强度 | 催化距今 | 市场阶段 | 操作 |
|------------|---------|---------|-----|
| 3/3条满足 | ≤15天 | 任意 | 建仓30-40% |
| 2/3条满足 | ≤15天 | 任意 | 建仓20-30% |
| 2/3条满足 | 15-30天 | 任意 | 建仓15%，等更近加仓 |
| 1/3条满足 | ≤15天 | **阶段A（复苏初期）** | 建仓15%（市场阶段降低门槛）|
| 1/3条满足 | 任意 | 阶段B/C | 继续等，不建仓 |
| 0条满足 | 任意 | 任意 | 继续等，不做左侧 |

**重要**：若一直输出"继续等"而无入场条件，必须明确说明"缺哪个止跌信号"，不能只说"等待"。

**左侧止损位：** 近期明确低点下方2-3%（具体价格，不是百分比描述）

**右侧触发位（左侧建仓后等这个加仓）：**
通常是MA10或MA20，需要收盘站上且当天量比>1.2x

### 轨迹C → 右侧再入流程

**回踩有效性判断（v4.2修正）：**
- 回踩到MA5附近且量能萎缩：强信号，直接入场
- 回踩到MA10附近且量能萎缩：正常信号，入场
- 跌破MA20，跌破幅度≤15%：**WAIT**（不REJECT）——等收回MA20上方后入场
- 跌破MA20，跌破幅度>15%：REJECT（趋势已破坏）

**回测依据**：7个"跌破MA20→REJECT"案例中，5个后续涨幅平均+28.8%（漏单率71%）。
3月整体回调导致几乎所有股票暂时跌破MA20，属于板块性回调而非个股问题。

**右侧入场条件：**
- 当天收盘站稳回踩位（不是日内触碰）
- 量比≤1.0x（缩量回踩，不是放量砸盘）

**右侧止损位：** 回踩低点下方

---

### 轨迹C+ → 趋势跟踪流程（v4.2新增）

**C+特征**：MA60向上，近20日持续领先板块，但价格没有出现标准回踩（从未回到MA5/MA10）。

**问题**：强势趋势股经常始终是C+，等MA5/MA10回踩等于永远等不到。
**回测依据**：002463沪电股份全程C+→WAIT，从81涨到133从未买入。

**C+入场条件（二选一）：**

方案一：短期回调入场
- 从近5日高点回调≥3% → 可入场（不需要回到MA5）
- 条件：回调当天量比 ≤ 1.0x（缩量，不是砸盘）

方案二：横盘突破入场
- 近5日连续未创新高（横盘整理）
- 某日收盘突破5日最高价 且 量比 ≥ 1.3x → 入场

**C+止损位：** 入场后跌破近5日最低点下方2%（不用MA止损，太远）

**C+仓位：** 30%（趋势跟踪风险高于回踩，仓位保守）

### 轨迹A / D → 不入场

等待信号转变为B或C，期间保持观察。

### 等待时：必须输出等待类型和监控方式（不能只说"继续等"）

**等待不是结束，是给出下一步触发条件。三种等待类型对应三种监控方式：**

| 等待类型 | 适用场景 | 监控方式 | 入场时机 |
|---------|---------|---------|---------|
| 事件驱动突破 | 催化≤10天，等市场开始定价 | **必须盯盘，设盘中价格提醒** | 价格盘中触碰突破价 + 量比≥1.5x → 当场买，不等收盘 |
| 止跌确认 | 急跌后次日确认 | **次日开盘后看前15分钟** | 开盘>昨收 + 前15分钟量比≥1.5x → 开盘15分钟内介入 |
| 技术修复 | 均线深度空头，等慢修复 | 每日收盘设提醒即可 | 收盘站上MA20 + 量比≥1.2x → 次日开盘介入 |

**"事件驱动突破"的核心逻辑**：你不是在涨了7%后才买，而是在价格突破阻力位的那一刻（盘中）就介入——彼时只涨了1-2%，不是追高。

### 通用：目标空间检验（入场前必做）

```
目标价 = 前期高点 或 下一个明确压力位
风险 = 入场价 - 止损价
收益 = 目标价 - 入场价
要求：收益/风险 ≥ 2
```

若算不出2倍以上的风险收益比，不入场。

## 第6层：量能确认（模式判断）

**不再只看今天量比，而是看近5-10天的量能模式。**

**健康的量能模式（加分）：**
- 上涨日成交量 > 下跌日成交量（持续多天）
- 回调期间量能逐日萎缩
- 止跌反弹当天量能明显高于前几个下跌日

**危险的量能模式（减分/否决）：**
- 下跌日量能持续放大（主力在出货）
- 反弹日量能极度萎缩（无人跟进，虚假反弹）
- 高位出现单日异常放量后次日滞涨（高位出货信号）

**缩量回调三个失效场景（保留）：**
- 板块主线已退潮
- 高位第一次放量长阴后缩量（无人接盘，非洗盘）
- 跌破关键均线后缩量（弱势缩量不是买点）

## 退出规则

| 情况 | 动作 |
|------|------|
| 跌破左侧入场止损位（近期低点下方） | 全部止损出场 |
| 跌破MA20且当天无法收回 | 减至半仓；次日仍破则清仓 |
| 催化事件兑现当天放量滞涨 | 分批止盈50% |
| 达到前高/目标区且出现缩量上影线 | 分批止盈，剩余半仓等突破或回落 |
| 板块主线出现退潮信号（ETF连续流出+板块破位） | 主动退出，不等止损 |

## 辅助维度（六层后的加深分析）

- **板块成分宽度**：是整体启动还是个股独走（第1层补充）
- **多日资金流向**：主力资金3-5日净流入趋势（第6层补充）
- **high_baseline**：股价在历史分位的位置，避免买在绝对高位（第5层补充）
- **ETF资金**：板块ETF是否有持续申购（第2层催化持续性）
- **相对强度**：个股近20日涨跌 vs 板块ETF涨跌（第4层轨迹判断核心依据）

## 背景与约束

- 用户资金约6万，无底仓时需要主动建仓，持仓1-2只，持有周期3-8周
- 没时间天天盯盘，决策在收盘后做，只能做周线级别判断
- 不做日内轮动；左侧介入是为了"保证上车"，不是投机

**Why:** v3的核心改变是承认"等待右侧信号有时意味着错过"——在催化时间窗口明确的事件驱动交易中，左侧止跌介入的期望值优于等待MA完全确认。
**How to apply:** 分析某只股票时，先判断它处于哪条轨迹（A/B/C/D），再根据轨迹类型输出对应的入场条件、止损位、目标价和仓位建议。不再输出简单的"通过/不通过"，而是输出"现在处于什么阶段、触发什么条件可以入场"。
