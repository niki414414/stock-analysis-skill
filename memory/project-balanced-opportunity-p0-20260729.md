# 均衡市场机会发现层 P0（2026-07-29）

## 目标

将原本相互分离的大盘状态、板块发现、沪深300质量池和催化公司池缝合为：

```text
市场状态 → 板块证据 → 多来源股票候选 → 六层个股分析
```

P0 只产生研究候选，不产生买入信号，不修改六层分析，也不重构 `top-picks`。

## 影子模拟结论

- 绝对行业广度在普涨修复日会让候选泛滥，必须使用“行业上涨比例减全市场上涨比例”。
- 行情与 `moneyflow` 发布时间可能不同，资金必须独立探测最新有效日期；空数据不能填0。
- 沪深300质量池当前缓存62只，只覆盖31个申万一级行业中的16个，适合作为质量标签，
  不适合作为全市场候选宇宙。
- 股票候选保留三个独立标签：
  - `quality_core`
  - `catalyst`
  - `market_response`
- 两个及以上独立标签才进入 `six_layer_priority`，单标签只观察。

## P0 实现

在 `market_opportunity_radar.py` 保留旧 `rotation_candidates`，新增：

- `sector_opportunity_map`
- `opportunity_snapshot_meta`

板块证据包括：

- 相对沪深300的当日/5日/20日强弱；
- 相对全市场广度；
- 最近5个有效资金日的流入天数和累计净流入；
- 大单/特大单订单规模代理；
- 现有非科技事件地图催化；
- 质量池、催化池和市场响应股票的标签合并。

板块状态采用门槛组合，不使用加权总分：

- `evidence_cluster`
- `research_candidate`
- `weak_or_unconfirmed`

## 数据源与语义

- 行情、成分、资金均使用 Tushare：
  - `index_daily`
  - `index_member_all`
  - `daily`
  - `moneyflow`
- 不因接口延迟或失败切换免费数据源。
- `price_date` 与 `moneyflow_date` 分别记录。
- 大单/特大单只代表订单规模代理，不能等同真实机构身份。
- 科技催化仍由 `market-outlook` 正式工作流 STEP 4 单独核验；P0 的事件自动匹配以
  非科技事件地图为主。

## 验收

- 13项单元测试通过。
- 2026-07-29真实 Tushare 端到端运行成功：
  - 31个申万一级行业；
  - 成分查询错误0；
  - 行情日期和资金日期均为20260729；
  - 质量池62只；
  - 旧 `rotation_candidates` 兼容保留。
- 收紧三个过宽别名：
  - 食品饮料不再用泛“消费”匹配；
  - 家用电器不再用“消费/出口”匹配；
  - 汽车不再用泛“电池”匹配储能事件。

## 下一阶段边界

先积累5/10日影子记录并验证资金连续性和相对广度是否带来增量，再决定是否：

- 让 `top-picks` 消费同一个机会快照；
- 接入业绩预告广度；
- 接入龙虎榜、机构调研、研报变化和热榜等 P1/P2 数据。
