## 信号/Verdict 标签对照

**客观信号 emoji**：

| 信号 | Emoji |
|------|-------|
| 买入（客观） | 🔵 |
| 持有（客观） | 🟡 |
| 观望（客观） | ⚪ |
| 卖出（客观） | 🟠 |
| 估值禁买/趋势破位 | 🔴 |

**用户 Verdict emoji**：

| 调整后得分 | 硬过滤 | Verdict | Emoji |
|----------|--------|---------|-------|
| ≥ 75 | 通过 | 适合您——考虑建仓 | ✅ |
| 60-74 | 通过 | 基本适合——少量观察 | 🟢 |
| 40-59 | 通过/已持仓 | 观望——等待更好时机 | ⚪ |
| < 40 | 通过 | 暂不适合 | 🟠 |
| 任意 | 未通过 | 不适合您 | ❌ |
| 已持仓（任意）| — | 持仓评估 | 📊 |

## 特殊场景

**所有股票都未通过硬过滤**：
- 解释为何都不适合
- 说明：当前最适合新建仓的条件（价格区间/板块/资金面要求）

**市场温度极热（sh300_weekly > 5%）**：
- 看板顶部加粗：⚠️ 当前市场极热，建议操作降一档（买入→少量/观望→谨慎）
