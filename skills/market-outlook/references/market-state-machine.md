# 大盘状态机 — 市场级报告固定框架 v2.0

> 数据来源：`scripts/market_state_fetcher.py`（2026-07-21新增自动化脚本，此前
> 需手动WebSearch/临时代码现拉数据）+ `top-picks`板块轮动雷达 + `event_map_query.py`
> window/corrections。触发方式：`/market-outlook` 技能。

## 定位

六层框架（analysis-prompt-template.md）是**个股工具**：市场判断（Layer0阶段+Layer1水位）只是给个股入场做否决门槛的输入参数，从不单独产出"这周大盘该怎么打"的结论。

本文件是给**市场级报告**（"下周大盘怎么看""这周该进攻还是防守"类请求）补的专门输出层，不替代、不修改六层框架本身。六层框架继续管个股，这份管大盘。

**触发场景**：用户问"下周大盘怎么走""这周该进攻还是防守""主线现在什么状态"，或任何要求做多股票/多事件综合研判的市场级报告。个股六层分析不套用此框架。

---

## 核心问题（每次输出前自问）

1. 下周大盘环境允许进攻吗？
2. 当前主线是强化、分歧、修复还是退潮？
3. 如果盘面和预期不一样，该看哪些信号修正判断？
4. 如果出现异常波动，结构与真实原因分别是什么？
5. 科技之外是否存在“资金 + 催化 + 公司质量”同时成立的机会？

报告写完，读者应该能不看细节就回答这五个问题。如果不能，说明堆了事件没给方向，重写。

## 一、四个状态判断（每次必须给出，且必须附证据）

### 1. 市场状态：进攻 / 震荡 / 防守 / 退潮

| 状态 | 判定证据（至少3项同向） |
|---|---|
| 进攻 | 指数站上MA20且上行、两市成交额较5日均值放大、上涨家数占比>55%、涨停数明显多于跌停(>15:1)、北向资金净流入 |
| 震荡 | 指数在MA20附近拉锯、成交额持平、上涨家数占比45-55%、涨跌停数接近 |
| 防守 | 指数跌破MA20但未加速、成交额萎缩、上涨家数占比<45%、跌停数上升但未失控 |
| 退潮 | 指数加速下跌、成交额恐慌性放大或彻底缩量、跌停数远超涨停(>10:1)、北向资金转为持续净流出 |

**关键陷阱**：指数涨跌本身会骗人——2026-07-10科创50指数-1.96%，但当日上涨家数占比69.2%、跌停仅4只，这是"权重股压制"不是"退潮"，必须用`market_environment.breadth.regime_label`（普涨/抱团集中/权重股压制/普跌）交叉验证指数涨跌，不能只看指数。

**回测验证（2026-07-11，849个交易日，2023-01至2026-07，覆盖AI牛市+2023-2024阴跌两种regime）**：

| regime_label | 3.5年全样本10日胜率(上证/创业板/科创50) | 结论 |
|---|---|---|
| 抱团/集中 | 42.4% / 45.8% / 47.5%，且3-5日更差 | ✅验证：短期(3-5日)最差档位，是唯一稳定的负面信号 |
| 普涨 | 58.8% / 55.4% / 51.1% | ✅验证：最健康档位，**但见下方"反转型普涨"专项说明——这个数字不能直接套用到"急跌后单日暴力反弹"这个子场景** |
| 普跌 | 52.1% / 45.1% / 47.9%（全样本） | ⚠️条件性：单看全样本已经不到50%，**不能当成通用买点信号**，见下方"逢跌买"专项说明 |
| 震荡偏强/偏弱 | 短样本(13个月)一度显示最强，但3.5年样本转弱甚至转负 | ❌短样本假象：13个月子样本得出的"震荡偏强最优"结论，拉长样本后不成立，提醒任何单一短窗口结论都要留意是否被当时的regime放大了 |

### "逢跌买"专项说明（v1.1新增，2026-07-11回测校准）

**不要把"普跌之后买入"当成脱离大盘context的机械规则。** 用2024-09作为分界点（用户体感的"AI叙事共振启动点"）重新切样本：

| 时期 | 普跌10日胜率(上证/创业板/科创50) |
|---|---|
| 2024-09前 | 43.9% / **30.2%** / 41.7% — 普跌之后普遍还要跌，是真退潮 |
| 2024-09后(AI主线共振期) | 61.9% / 62.7% / 55.1% — 普跌之后普遍反弹，是错杀买点 |

同一个"普跌"标签，在两个不同regime下的胜率能差出30个百分点。**这个优势建立在"AI资本开支驱动的科技牛市主线仍然成立"这个前提上**，不是一条永久规律。判断当前是否还在这个前提里，看外部证据（费城半导体指数动能、海外云厂商capex指引、Mag7财报），不能只看A股自己的价格行为——否则就是循环论证（"因为在涨所以是牛市，因为是牛市所以该买跌"）。

### "反转型普涨"专项说明（v1.2新增，2026-07-21发现）

**不要把"急跌后单日暴力反弹=普涨"和"稳定趋势中的普涨"当成同一件事套用同一个胜率数字。** 上面表格里"普涨58.8%/55.4%/51.1%"是全部849个交易日里**任何**广度健康的日子算出来的均值，没有区分"这一天之前市场是平稳的还是刚经历多日暴跌"——这是聚合掩盖异质性的典型问题，和`feedback_high_baseline_limitation`、均线偏离度base-rate问题是同一类教训。

**2026-07-21现场校准**：创业板指2015-2026年"前5日累计跌幅≤-5% 且 当日单日涨幅≥6%"的精确匹配样本只有5次（含当次），4次有完整后续数据，且全部集中在2015年股灾去杠杆期（与当下"两融连续13天去杠杆"机制最相似的历史场景）：

| 日期 | 当日涨幅 | 5日后 | 10日后 | 20日后 |
|---|---|---|---|---|
| 2015-06-30 | +6.3% | -17.7% | -4.6% | -9.7% |
| 2015-08-04 | +6.1% | +6.0% | -1.6% | -25.8% |
| 2015-08-28 | +6.3% | -3.9% | -13.7% | +0.8% |
| 2015-09-16 | +7.2% | +7.9% | +8.1% | +21.7% |

10日后上涨概率仅25%（1/4），20日中位数-4.44%且方差极大（+21.7%到-25.8%都有）。样本量太小（n=4）不足以定出一个新的精确胜率数字，但足以确认："反转型普涨"是一个历史上表现明显弱于、且波动明显大于"普涨"整体均值的子场景，**不能直接引用58.8%这个数字给它背书**。

**判定规则**：当`regime_label`从非普涨（抱团/集中、权重股压制、普跌）在1个交易日内跳到普涨，且跳变前有连续多日(≥3日)的普跌或急跌记录时，判定为"反转型普涨"，报告中必须：
1. 明确标注"这是反转型普涨，不是趋势延续型普涨，历史参考样本小（2015年至今仅5例）、方差大，不能直接套用普涨整体58.8%的胜率数字"
2. 在给出情景概率时相应下调确定性，不能按整体"普涨"的健康档位处理
3. 列出接下来2-3个交易日需要确认的具体信号（去杠杆类指标是否真正止跌、反弹涨幅是否被回吐、成交量是否持续放大而非当天一次性冲高）再决定是否上调判断

**关于"这次不一样"**：判断依据是外部证据（两融是否真止跌、维持担保比例是否持续修复），不能只看当天指数涨了多少——这和上面"逢跌买"专项说明的方法论一致：任何"这次不一样"的判断都需要脱离价格本身的独立验证，否则是循环论证。

**输出规则**：报告里判断为"普跌"状态时，必须同时输出这条条件性提醒，并注明当前判断"AI主线是否仍然成立"的依据是什么；不能只说"普跌，历史上是买点"就结束。

### 背离占比（替代原六层Layer0"分化期"，v1.1新增）

原六层框架的"分化期高位结构分化"（原称"阶段D"）从未被独立验证过，2026-07-11尝试用"连续N天背离"回测，发现这种严格定义在A股历史上极度稀有（3.5年只出现2-3次"连续≥3天"），测不出统计意义。改用**滚动10日背离占比**（过去10个交易日中"抱团/集中"或"权重股压制"天数占比）作为连续型指标后，样本充分(n=282-518)且效果清晰：

| 过去10日背离占比 | 10日后均值(上证/创业板/科创50) |
|---|---|
| 0-10%(几乎无背离) | +0.64% / +1.05% / +1.35% |
| 10-30% | -0.29% / +0.10% / +0.32% |

背离占比从0-10%升到10-30%，三个指数前瞻收益全部走弱。**用这个滚动占比替代原六层Layer0的"复苏期/主升期/过热期/分化期"判断**（原称"阶段ABCD"）——原阶段判断因未经验证，已从"改变仓位上限的硬性门槛"降级为"报告中的背景描述"，不再机械触发仓位调整。

### 2. 主线状态：强化 / 分歧 / 修复 / 退潮 / 新主线试探

| 状态 | 判定证据 |
|---|---|
| 强化 | 龙头股创新高或站稳前高、板块内跟涨面扩大、催化窗口model显示🔴/🟡新催化持续出现、资金（ETF/北向）持续净流入该主线 |
| 分歧 | 龙头股滞涨或高位震荡、板块内涨跌参半、corrections表出现"高拥挤/需要验证"类修正、资金流入放缓或转为流出 |
| 修复 | 主线经历过回调后止跌，跟涨面重新扩大，但尚未创新高 |
| 退潮 | 龙头股持续破位、板块资金持续流出、window模型显示该主线事件集中落入⚪(退出/窗口结束) |
| 新主线试探 | 出现window模型🔴/🚀新事件但尚无板块级资金确认（个别龙头动，跟涨面未扩散），或corrections表新增一条此前未覆盖的方向 |

**数据来源**：event_map_query.py的`window`命令（催化新鲜度）+ `corrections`表（本周修正）+ 龙头股/ETF价格行为，三者交叉判断，不能只看其中一个。

### 3. 风格状态：科技占优 / 非科技占优 / 高低切换 / 红利银行防守 / 存量跷跷板 / 全市场增量

判定依据：科创50/创业板 vs 沪深300/中证1000 vs 中证银行/红利指数的近5日、近20日相对强弱；两市成交额水位（>3.5万亿=增量特征更明显，<2.5万亿=存量特征更明显，存量下更容易出现跷跷板/高低切换）。

**细分题材/避险资金层**（2026-07-22新增，`subsector_basket_momentum`+`macro_hedge_baskets`）：上面这组指数级别的对比只能回答"科技vs非科技"这种大方向问题，容易漏掉两类信号——①申万一级行业内部被稀释的细分题材（如"有色金属"把贵金属和工业金属混在一起，贵金属单日大涨会被稀释成行业整体涨幅平平）；②完全独立于科技/非科技这条主轴之外的资金去向（贵金属这类避险资金，不受"科技占优/非科技占优"这套框架约束，可能在科技和非科技都走弱时同时走强）。2026-07-22实测：科创50/创业板当日双双下跌超2%，同时贵金属篮子涨+6.7%——这是一个风格判断六分类里都装不下的独立信号，必须单独报告，不能强行归到"非科技占优"或"红利银行防守"里（贵金属不是红利股，逻辑也不是银行防守逻辑）。

### 4. 风险偏好：上升 / 持平 / 下降 / 局部上升但整体分化

判定依据：两市成交额趋势（连续放大=上升，连续萎缩=下降）、涨停家数趋势、北向资金方向、中证1000/微盘股相对沪深300的强弱（风险偏好上升时小盘更强）、恐慌指标（跌停数/单日普跌频率）。"局部上升但整体分化"专门对应"指数或个别主线在涨、但多数个股/多数行业在跌"这种Layer1分歧度检查抓的情形。

**护盘/托底资金代理指标**（2026-07-21新增）：急跌后是否有护盘资金入场，直接看`market_state_fetcher.py`的`national_team_proxy`字段——宽基/科技类ETF份额单日跳升幅度+日期，跟官方护盘公告日期是否吻合。2026-07-21实测案例：7/19晚中国国新/诚通公告护盘后，科创50ETF(588000.SH)7/20单日份额跳升+20.4%、创业板ETF(159915.SZ)7/21跳升+18.2%，都精确对上公告后的交易日；而中证1000ETF/半导体ETF同期最大跳升日分别在7/13和7/2，跟这波护盘无关——这个"时点吻合度+跳升幅度差异"的比较方式，比单看某一天的份额变化更能确认"护盘资金是否真实入场、偏向哪个方向"。**局限**：ETF份额申购匿名，不能100%确认买方是"国家队"，只是历史模式高度吻合的间接代理，不能单独作为决策依据，需要跟官方公告的WebSearch核实交叉验证。

**两融余额高位预警信号**（2026-07-21新增回测验证）：两融余额滚动250日(约1年)分位从<90%首次穿越到≥90%，是一个有效的**短期（约20个交易日/1个月）**风险偏好转弱信号——2020-2026回测20个信号样本，沪深300/上证指数信号后20日胜率仅25%/35%（无条件基准应有50%+），均值也明显低于基准；但**40-60日后效果基本消失甚至不一致**，不能当成"顶部确认"信号，只能理解为"近1个月脆弱性上升，容易被强平/踩踏放大波动"。数据来源：`market_state_fetcher.py`的`fetch_margin_rolling_signal()`，每次跑market-outlook现算，不要用之前的快照数字——两融每天在变，"当前是否处于预警窗口内"必须用当天最新数据判断。

**已知局限**（回测中发现）：这个信号只在从<90%穿越到≥90%那一刻触发一次；如果两融余额突破90%后长期维持高位甚至持续创新高、从未跌回90%以下，中间不会再产生新信号——对"持续在高位加速"这种可能更危险的情况有盲区，使用时要知道这条规则不是万能的。

### 5. 异常波动：结构诊断与原因核验（v2.0新增）

异常波动不能只写“市场情绪影响”。先用行情数据确定结构，再用外部证据解释原因：

| 输出项 | 要求 |
|---|---|
| 异常结构 | 科技风格冲击、全市场风险冲击、流动性踩踏、风险偏好修复或混合型 |
| 主要原因 | 至少一条来源可靠、发生时间与波动吻合、能解释主要受影响资产的证据 |
| 次要原因 | 有证据但覆盖面或解释力较弱 |
| 已排除说法 | 时点不符、只能解释局部或无原始来源的说法 |
| 置信度 | 高/中/低，并列出下一条能提高或推翻判断的证据 |

**硬性边界**：价格、成交量、广度只能确认结构，不能单独证明新闻原因。标题相似、
事后评论和市场传言不能直接升格为主要原因。

### 6. 非科技机会雷达（v2.0新增）

非科技轮动采用四道门，不依赖当前缺失的非科技 `sectors_status` 表：

| 门槛 | 核心问题 | 不通过时 |
|---|---|---|
| 资金 | 当日和5日相对强势是否持续，板块内部是否扩散 | 仅观察 |
| 催化 | 是否有政策、订单、涨价、供需或业绩理由，且时点有效 | 不进入操作池 |
| 公司 | 主营相关度、业绩质量、估值和治理是否过关 | 换标的或放弃 |
| 价格 | 是否有可执行触发位、止损位和合理盈亏比 | 等待，不追涨 |

2023-01至2026-07影子回测显示：申万非科技行业的5日相对强势，无论简单追前三，
还是叠加20日、持续性和成交额确认，后续5日/10日均未形成稳健正超额。因此，
**强势只能作为发现器，永远不能机械翻译为买入信号**。

事件地图无覆盖不等于没有催化，必须触发外部补漏搜索；但外部搜索后仍找不到可靠催化，
结论必须是“不进入操作池”，不能为了凑轮动机会降低证据标准。

## 二、情景→动作翻译表（固定格式）

不写"情景A概率50%"就完事，必须展开：

| 情景 | 概率 | 触发条件 | 观察指标 | 盘面特征 | 应对框架 |
|---|---:|---|---|---|---|
| {名称} | {%} | {什么条件成立时这个情景在发生} | {用什么数据确认} | {指数/涨跌家数/主线表现的具体样子} | 是否适合进攻/降低风险/等待验证/只观察；优先关注哪些方向；不宜追高哪些方向；出现什么信号需要改判 |

应对框架不写具体买卖点，只写姿态（进攻/防守/观察）和方向优先级，具体买卖点留给六层框架处理个股。

## 三、下周作战地图（每份市场级报告固定收尾模块）

```markdown
# 下周作战地图

## 1. 本周基础判断（一句话）
当前市场处于{进攻/震荡/防守/退潮}，主线处于{强化/分歧/修复/退潮/新主线试探}，
风险偏好{上升/持平/下降/局部上升但整体分化}。

## 四、报告开头固定格式（读者5秒内抓住方向）

每次市场级报告，第一屏必须是（详细展开放后面）：

```
【一句话结论】{...}
市场状态：{进攻/震荡/防守/退潮} — 证据：{...}
主线状态：{强化/分歧/修复/退潮/新主线试探} — 证据：{...}
风险偏好：{上升/持平/下降/局部分化} — 证据：{...}
异常波动：{未触发/结构标签} — 主要原因：{已核验原因/待核验}
非科技机会：{轮动候选/题材试探/防守候选/暂无} — 证据：{资金+催化}
下周关键触发器：{日期+事件，最多5个}
应对框架：{进攻/防守/观察，一句话}

|---|---|---|---|---|---|

| 板块 | 资金性质 | 有效催化 | 地图覆盖 | 公司候选及质量 | 结论 | 入场触发 | 失效条件 |
