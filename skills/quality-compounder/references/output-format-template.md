# 输出格式模板

```

  /quality-compounder 沪深300十年质量-价值筛选 — {today}
  硬过滤后基数：{N}只 → Stage 1候选：{M}只
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【Stage 1 候选】（按CAGR净利润降序）
代码      名称    行业    PE   CAGR净利润 CAGR营收 下滑年数 最近年排名
{ts_code} {name} {industry} {pe} {cagr_np}% {cagr_rev}% {down_years} {rank_last_year}
...

【Stage 2 决策表】
{ts_code} {name}  行业内排名: {rank}/{total}（仅沪深300内，非全市场）
  主营集中度: {top_segment_pct}% 或 "数据不可得，需人工核实"
  订单情况: 本工具不覆盖，需人工核实

  - {quality_note_2}
  ...（无预警项则写"未触发预警阈值"）

  下一步
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  对感兴趣的候选，运行 /stock-analysis {代码} 做技术面/催化面验证再决定是否入场。
```

**输出规则**：
- Stage 1 表格全部展示（候选池预期几十只量级，不需要截断）
- Stage 2 每只候选独立成段，预警项用 `-` 列出，无预警写"未触发预警阈值"
- 不做单一综合分排序——现金流质量/杠杆/周转率是不同维度的风险信号，强行加总会掩盖具体是哪类风险
- 若 Stage 1 候选为0，直接说明"当前阈值下无候选通过，可考虑放宽 config/thresholds.yaml"，不要勉强凑数
