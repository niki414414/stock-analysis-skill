## 每只股票卡片格式

```
  ┌ #{rank_in_theme}  {code} {name}  [{subsector_label}]  {score}分  {catalyst_emoji}{catalyst_type}
  │  当前价 {price}元    距前高 {distance:+.1f}%（前高基线 {high_baseline}元）
  │  资金5日 {fund5d:+.2f}亿   板块宽度 {breadth:.0f}%   量比 {vol_ratio}
  └  操作建议：{入场区间或条件}   止损参考：{MA级别} {stop_price}元
```

字段说明：
- `rank_in_theme`：在本主线内的排名（#1/#2）
- `catalyst_emoji`：✅结构性 / ✅事件型 / ⚠️纯动量
- `distance`：`(current_price - high_baseline) / high_baseline * 100`；负数=距前高还有空间，正数=已超越
- `high_baseline`：近120日OHLCV排除最近20日的最高价（来自 stock_data_fetcher 的 high_baseline 字段）
- `breadth`：sector_breadth.follow_stock_up_pct × 100，即板块今日上涨股票比例

|-----------|------|

| 70–79     | ✅ 精选 |
| 60–69     | 🟢 候选 |
| < 60      | 不应出现（内部过滤） |

## 收缩期特殊格式

看板顶部加粗警告（置于所有内容之前）：

```
⚠️⚠️ 市场收缩期（{X}/5），新仓仓位降半，优先参考防御主线候选。 ⚠️⚠️
```

操作建议中仓位数字自动 × 0.5。
