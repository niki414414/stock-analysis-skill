# Top Picks — 催化驱动左侧扫描 v4.2

**核心逻辑**：
```
活跃事件（催化分≥5）→ SQLite公司—事件关系 → 价格未充分跟随 → 启动就绪度
```

**与旧扫描器的区别**：
- 旧 signal_scanner：价格异动 → 找催化（右侧，已删除）
- 旧 prelaunch_scanner：技术蓄力 → 找催化（技术右侧，已删除）
- 现在：催化活跃 → 价格还没动 → 量能/支撑/收敛三维判断（左侧）

**启动就绪度（0-10）**：
- ① 量能方向（5分）：近5日量能趋势↑(+3) + vol_ratio>1.2(+2)
- ② 支撑位临近（3分）：贴近MA60 <5%(+3)，5-15%(+1)
- ③ 价格收敛（2分）：近5日振幅<3%(+2)，3-6%(+1)

## 工作流

```
STEP 0   市场环境快速判断
STEP 1   运行催化左侧扫描器（~4分钟，243只）
STEP 2   输出分层结果 + 赛道分布
STEP 3   引导用户进入 /stock-analysis
```

---

## STEP 0: 市场环境判断

5指标快速判断（各1分，全部实时获取，不依赖yaml）：沪深300在MA60上方、北向近20日净流入、今日涨停>50、强势股持续新高、国债收益率平稳。

≥3分 = 扩张期；≤2分 = 收缩期，在看板顶部加 ⚠️"收缩期，所有新仓仓位降半"。

**板块轮动雷达（扫描器自动输出，无需单独触发）**：
扫描器启动时自动拉取15个申万一级行业指数的20日/5日涨幅，在扫描结果前输出。
- 🔵 = 科技主线（电子/计算机/通信）
- ⚡ = 非科技异动（近5日发力且20日跌幅<10%，可能是轮动启动信号）
- 若有⚡板块出现：在扫描结束后提示用户"是否针对该方向做个股分析"

## 错误处理

| 场景 | 处理 |
|------|------|
| 无就绪候选 | 输出预热列表 + "当前无左侧窗口，建议持币" |
| tushare拉取失败 | 检查token；跳过失败的个股，其余正常输出 |
| SQLite公司关系读取失败 | 自动记录警告并回退Excel；`--company-source excel`可显式双读 |
| 事件地图目录找不到 | 提示检查 ~/Desktop/tz/科技产业事件/csv0MMDD/ |
| 运行超时(>6分钟) | 提示网络慢，建议 --min-event-score 6 缩小范围 |
