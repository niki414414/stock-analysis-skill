## 核心发现

### 1. A轨迹漏单依然是最大缺口（v4.2已发现，v4.3未根本解决）

raw_traj=A 共67个（占比45.6%），全部REJECT，准确率56.7%但平均后续收益仍有+6.4%，**个体案例最高达+93.6%（长电科技600584，4-30信号）**。

v4.3新增的A→A⚠️升级条件（sector_priority==1 且 主升/启动 且 近20日>10%）只触发了11次，且触发后**决策仍是WAIT**（因Layer2/3未自动化），并未真正转化为入场——A⚠️这11个信号准确率36.4%，平均收益+19.3%，漏单率仍高达7/11。

**根本问题**：升级条件本身是滞后指标（要求已经涨了20日>10%才升级），但在"复苏期"，恰恰是**还没涨起来**的A轨迹个股即将启动。

### 2. "D+E占比放宽阈值"假设被验证为错误 ❌

最初假设：当D+E轨迹占比高（>35%，代表普涨广度大）时，放宽D（10%回调阈值）和E（5%回调阈值）的入场门槛，给出趋势延续型ENTER。

测试结果：总体准确率从48.3% → **46.9%（下降）**，新增19个ENTER胜率仅47.4%（接近随机），且出现一个-43.22%的极端亏损案例（002335科华数据，5-15信号，D轨迹）。

**这是个有价值的负向发现**：D+E占比在5-15信号日达到51%，恰好是市场即将走平/调整的时点——**高位扩散（很多股票同时处于D/E）本身是过热/分化信号，不是"普涨延续"信号**。这反向验证了v4.3新增的"阶段D：高位结构性分化"概念是有依据的，只是本次Layer0未自动判定阶段D（需要全市场宽度数据），导致5-15这个信号日被误判为普通阶段B。

### 3. 验证有效："复苏延续窗口"A轨迹左侧规则 ✅（v4.4候选）

**规则**：当本信号日或上一信号日market_stage=="A"（即"复苏期刚出现"及其后一个信号周期内），A轨迹个股若MA60斜率不深跌（>-1%/5日），升级为A⚠️并给出**左侧20%试探仓位**入场，止损=近5日低点-3%。

**测试结果**（应用于4-15和4-30两个信号日的A轨迹）：
- 总体准确率：48.3% → **52.4%**
- 新增25个ENTER信号：胜率68%（17/25 ≥3%），平均收益+13.5%，亏损6个（最差-8.7%）
- 8个原本"正确避开"的信号变为"错误入场"，但损失普遍可控（-2.85%~-8.69%），且若按-3%止损执行，实际组合影响在20%仓位×3%=0.6%量级

**为什么比v4.4c（要求MA60斜率>0才入场）好**：v4.4c几乎不触发（147个信号中只新增1个ENTER），印证v4.2已有结论——"等MA60转向上"在复苏期太晚，左侧布局的本质就是在MA60还没转向时进场。

## v4.4候选规则总结（待评估是否纳入trading-framework-checklist.md）

```
新增规则（建议命名：复苏延续期A轨迹左侧）：

IF (本信号周期 market_stage == "A") OR (上一信号周期 market_stage == "A"):
    IF raw_traj == "A" AND ma60_slope > -1.0%/5日:
        → 升级为 A⚠️，给出左侧20%试探仓位ENTER
        → 止损 = 近5日最低点 × 0.97
        → 保留v4.3原有的A⚠️升级条件（priority1+主升/启动+20日>10%）作为补充触发，
          两条件任一满足即可升级
```

**注意**：第2点的负向发现（D+E占比放宽阈值无效）建议**不要**纳入框架——维持v4.3现状（D/E回调阈值不变）。

## 局限性声明（与v4.2一致+新增）

1. **样本窗口单一且极端**：2026年4月中-6月初是一轮罕见的强势普涨行情（几乎所有股票15日内都有正收益），本回测的"漏单率"在震荡市/下跌市可能完全不同甚至反转——v4.4候选规则的"左侧20%试探"在弱势市场中风险特征会不同，需要在不同市场环境样本中重新验证才能正式纳入框架
2. **"板块"用沪深300代理**：rel_20d（个股vs板块相对强度）实际算的是个股vs沪深300，子赛道层面的轮动信息丢失
3. **Layer2/3未自动化**：A⚠️/Bridge等依赖催化判断的规则，本回测中触发后仅停留在"标签"层面，未反映真实框架中Layer2/3会进一步筛选掉部分A⚠️（理论上能降低A⚠️→ENTER的漏单/错误入场率）
4. **阶段D未自动判定**：5-15信号日D+E占比51%很可能已构成"阶段D高位结构分化"，但Layer0脚本只输出A/B/C，导致该信号日被当作普通阶段B处理（不过本次该信号日框架表现反而是最好的，说明阶段B规则在那个时点也凑巧合适）
5. **回测脚本**：`/tmp/backtest_v43/backtest_v43.py`（48.3%基准）+ `analyze.py`/`analyze2.py`/`analyze3.py`（假设检验），临时文件未持久化到skills目录，如需复用应迁移至`~/.claude/skills/stock-analysis/references/`
