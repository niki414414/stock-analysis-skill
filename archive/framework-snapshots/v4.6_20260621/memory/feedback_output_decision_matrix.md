每次个股分析结论部分，必须输出**操作决策表**，格式为"如果观察到X条件，执行Y操作"。

**不是这种：**
- 看涨：目标价XX
- 震荡：持有等待
- 看跌：止损

**而是这种：**

| 观察到的条件（价格区间 / 量比 / K线形态） | 对应操作 |
|---|---|
| 价格在XX-XX区间，量比<1.0，缩量横 | 继续持有，不追不减 |
| 价格突破XX，量比≥1.3 | 加仓100股 |
| 价格回踩至MA5（约XX元），量比<0.8 | 补仓机会，加仓100股 |
| 价格跌破MA10（约XX元）且当日未收回 | 警戒，减半仓 |
| 价格跌破MA20（约XX元） | 硬止损，清仓 |

**核心原则**：用户看完表，盯着盘面就能对号入座，不需要再做二次判断。

**Why**：用户在14:26这种盘中节点需要的不是分析逻辑，而是"现在看到这个，我该按哪个键"。概率/方向判断已经在六层分析里完成，决策表是把结论翻译成可执行指令。

**How to apply**：
- 每次六层分析输出的"操作建议"部分，用表格形式列出至少4个可观察状态（进场触发、加仓触发、警戒线、止损线）
- 价格和量比用具体数字，不用"偏高/偏低"等描述性词汇
- 均线数值标注"动态"提示（因为每日收盘后会变化）
- 持仓评估模式下额外增加"减仓触发"这一行
- 复杂度说明：不要求穷举所有组合，只覆盖最可能出现的4-6个状态即可
