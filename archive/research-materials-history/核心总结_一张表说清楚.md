## 极简决策树：遇到问题时该怎么办？

```
问题发生 → 立即查表确认是否在"触发条件"中
              ↓
         是否在P0(最高优先级)?
         ├─ 是 → 立即减仓
         └─ 否 → 继续查表
              ↓
         影响多少公司(1/2/3个以上)?
         ├─ 1个 → 单独减仓该品种
         ├─ 2个 → 整体降低风险敞口
         └─ 3个+ → 重新配置组合
              ↓
         是否有"对冲"机会?
         ├─ 是 → 减仓高风险品种,加仓防守品种(如高速PCB)
         └─ 否 → 增加现金比例,等待市场反应充分
```

## 最重要的三个数字

### 数字1：36个月

这是**高速PCB和先进封装的"黄金确定期"**。

在这36个月内(2026-2029年)，这两个赛道的增长逻辑很难被破坏：
- 高速PCB：服务器是5年一迭代的刚需设备，每次迭代都需要升级PCB
- 先进封装：Chiplet已经成为产业共识，各大芯片厂都在用

**投资建议：** 这36个月是最安全的配置期。如无重大变化，可以持有。

---

### 数字2：24个月

这是**国产AI芯片的"确定期"和"政策倚重期"**。

寒武纪/海光目前的增长是建立在：
- ✅ 订单已经验证 (2025年已有业绩兑现)
- ✅ 政策支持 (战略级别)
- ⚠️ 但政策可能在2028年后出现调整

**投资建议：** 这24个月最多看到2028年上半年。到2028年下半年，必须根据政策信号调整预期。

---

### 数字3：12个月

这是**光模块的"最后黄金期"**。

1.6T光模块还能热1-2个季度，但：
- 3.2T可能比预期更快到来
- 硅光/CPO的商业化可能比预期更快

**投资建议：** 光模块最多看到2027年上半年。如果你还在持有，2027年Q2季度就应该开始减仓。

## 最重要的三个监测指标(优先顺序)

### 优先级1：云厂商AI capex增速 🔴

这是**"需求端是否仍然健康"的最直接信号**。

```
检查方式：
1. 每季度看Meta/Google/AWS/MSFT的财报或电话会
2. 找"AI capex"或"capital expenditure for AI"的指引
3. 看同比增速是否还在 15-30% 的区间

预警：
• 如果Q2/Q3的年度capex指引从"增长20%" → "增长10%" 
  → 说明需求开始降速 → 提前减仓

崩塌：
• 如果任意一家宣布"冻结AI投资"或"负增长"
  → 说明需求见顶 → 立即调整组合
```

---

### 优先级2：龙头公司的毛利率环比变化 🟠

这是**"行业竞争是否开始恶化"的最直接信号**。

```
检查方式：
1. 每季度看沪电/长电/胜宏的季度财报
2. 计算毛利率环比变化(本季度 vs 上季度)
3. 看是否出现"持续下降"的趋势

预警：
• 单季度环比下降 2-3% → 正常(产能爬坡)
• 连续两个季度下降 > 2% → 竞争加剧信号
• 环比下降 > 4% → 必须检查原因(产能过剩?价格战?)

应对：
• 如果是"产能爬坡"导致的毛利率下降,但收入增长补偿 → 问题不大
• 如果是"竞争加剧"导致的下降,收入增长无法补偿 → 需要减仓
```

---

### 优先级3：美国出口管制清单措辞变化 🟠

这是**"政策突变风险"的最直接信号**。

```
检查方式：
1. 每月看一次美国商务部工业安全局(BIS)的出口管制清单
2. 特别关注"AI芯片"、"半导体制造设备"相关条目
3. 看措辞是否从"受限"变成"禁止"

当前(2026年5月)的措辞：
• "800G/1.6T光模块：受出口管制" ← 有条件允许
• "AI数据中心GPU：禁止" ← 完全禁止
• "晶圆代工设备(EUV)：禁止" ← 完全禁止

预警信号：
• 如果看到新增"AI芯片(包括国产替代品)：禁止"
  → 立即政策升级 → 国产AI芯片(寒武纪/海光)立即减仓至5%

最高警报：
• 如果直接看到"晶圆代工禁止" → 整个国产产业链面临重组
  → 整体降低风险敞口 40%
```

## 最后一个清单：今天(2026年5月)应该做的5件事

```
✅ 事项1：建立"监测系统"
   操作：在你的记事本/Excel里建立一个"季度监测清单"
   目的：不要相信你的记忆力,定期检查就不容易偏离框架

✅ 事项2：设定"止损线"
   操作：决定:如果光模块跌到X价格/如果毛利率跌到X%,就立即减仓
   目的：防止"这次会不一样"的心理陷阱

✅ 事项3：确定"现金比例"
   操作：决定保留5-15%现金,为可能的机遇或风险预留
   目的：要么在错误时被迫持有现金,不如主动保留

✅ 事项4：建立"情景计划"
   操作：写下"如果X发生,我就做Y"的if-then计划
   目的：危险时刻不要想太多,按计划执行就行

✅ 事项5：设定"复盘周期"
   操作：决定每个季度(3个月)一定要做一次全面复盘
   目的：定期反思比临时抱佛脚更有效
```
